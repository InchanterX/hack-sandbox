# Диагностика hack-sandbox

- `orch-ops get pods -n hack-sandbox`: код выхода 2. CLI отклонила `pods`: поддерживается только форма `pod`. Ответ JSON не получен; по этой команде нельзя судить о наличии подов.
- Дополнительная проверка `orch-ops get pod -n hack-sandbox`: код выхода 0, ответ `ok: true`, список подов пуст. Имена и фазы отсутствуют.
- `orch-ops events -n hack-sandbox`: код выхода 0, ответ `ok: true`, событий 0; причины событий отсутствуют.

Записанные коды относятся к указанным первоначальным командам. Пустые списки отражают ответы запросов и сами по себе не подтверждают состояние всего кластера.
