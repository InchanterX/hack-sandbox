# Дизайн

## Настроение и референсы

Спокойный рабочий инструмент: светлый фон, одна колонка по центру (макс. 720 px), много воздуха, моноширинный
шрифт для выражений и результатов. Без картинок и иллюстраций.

## Цвета и типографика

| Токен | Значение | Где |
|---|---|---|
| `--color-bg` | `#f7f7f8` | фон страницы |
| `--color-surface` | `#ffffff` | карточки, таблица, формы |
| `--color-text` | `#1d1d1f` | основной текст |
| `--color-muted` | `#6e6e73` | подписи, время |
| `--color-accent` | `#2f6fed` | кнопки, ссылки, фокус |
| `--color-queued` | `#8e8e93` | статус «в очереди» |
| `--color-running` | `#d98b00` | статус «выполняется» (с анимированной точкой) |
| `--color-done` | `#1f9d55` | статус «готово» |
| `--color-failed` | `#d64545` | статус «ошибка», тексты ошибок |
| `--radius` | `8px` | карточки, поля, кнопки |
| `--space` | `8px` | шаг отступов (кратные) |

Шрифты: системный sans-serif (`system-ui`) для интерфейса, `ui-monospace` для выражений и результатов.
Размер текста 16 px, заголовок страницы 24 px.

## Экраны

| Экран | Для кого | Главное действие | Состояния |
|---|---|---|---|
| Вход (`/login`) | гость | войти | ошибка «неверный логин или пароль»; загрузка на кнопке |
| Регистрация (`/register`) | гость | создать аккаунт | «логин занят», ошибки валидации у полей |
| Задачи (`/`) | пользователь | отправить выражение | пусто («Задач пока нет — отправьте первое выражение»), загрузка, ошибка сети с кнопкой «Повторить» |

Экран «Задачи»:
- Шапка: «Calc Queue», логин пользователя, кнопка «Выйти».
- Форма: поле выражения (моноширинное, placeholder `2 + 3 * (4 - 1)`) и кнопка «Вычислить»; ошибка синтаксиса —
  под полем.
- Список: выражение, статус (`StatusBadge`), результат или текст ошибки, время создания; действия «Изменить»
  (только `queued`, превращает строку в поле с «Сохранить» / «Отмена») и «Удалить» (скрыто у `running`).

## Адаптивность

Телефон (от 360 px) и ноутбук. До 640 px список — карточки, шире — таблица.
